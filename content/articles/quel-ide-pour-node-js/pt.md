## Eclipse:

Para trabalhar com Node.JS mais facilmente, é possível instalar o plugin "NodeClipse", disponível [aqui][1].

## Netbeans:

Para mim, o NetBeans está mais ou menos no mesmo nível do Eclipse, e acho a interface muito antiquada. Incluo-o para citar as poucas contribuições oferecidas para Node.JS:

- [um primeiro plugin][plugin1]
- [outro que parece mais interessante][plugin2]

## Webstorm:

O concorrente mais em voga do Eclipse é o [IntelliJ][2], que tem uma versão especialmente concebida para Node.JS: o [Webstorm][3].

O [Webstorm][3] permite criar esqueletos de projeto, entre eles um bastante interessante porque permite começar bem com Node.JS

> NodeJS (Node express app)

- Escolha de um template para as páginas:

    ```
    Template Engine : Jade, ejs, jshtml, hogan.js
    ```

- Escolha do motor para o CSS:

    ```
    Stylesheet Engine : CSS, LESS, Stylus
    ```

## Adobe Brackets (♥ Karlito):

O [Adobe Brackets][5] é um editor feito para design e desenvolvimento e, como a maioria dos editores recentes, suporta diretamente o [Node.JS][plugin3] e o [desenvolvimento **ao vivo**][plugin4].
