## Eclipse:

Para trabajar con Node.JS más fácilmente, se puede instalar el plugin "NodeClipse", disponible [aquí][1].

## Netbeans:

Para mí, NetBeans está más o menos al mismo nivel que Eclipse y su interfaz me parece muy anticuada. Lo añado para mencionar las pocas aportaciones que ofrece para Node.JS:

- [un primer plugin][plugin1]
- [otro que parece más interesante][plugin2]

## Webstorm:

El competidor de Eclipse más de moda es [IntelliJ][2], que tiene una versión especialmente pensada para Node.JS: [Webstorm][3].

[Webstorm][3] permite crear esqueletos de proyecto, entre ellos uno bastante interesante porque permite empezar bien con Node.JS

> NodeJS (Node express app)

- Elección de una plantilla para las páginas:

    ```
    Template Engine : Jade, ejs, jshtml, hogan.js
    ```

- Elección del motor para el CSS:

    ```
    Stylesheet Engine : CSS, LESS, Stylus
    ```

## Sublime Text:

Sitio oficial [aquí][4].

## Adobe Brackets (♥ Karlito):

[Adobe Brackets][5] es un editor pensado para el diseño y el desarrollo y, como la mayoría de los editores recientes, admite directamente [Node.JS][plugin3] y el [desarrollo en **vivo**][plugin4].
