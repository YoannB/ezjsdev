## Eclipse :

Pour mettre en œuvre Node.JS plus facilement, on peut installer le plugin "NodeClipse" disponible [ici][1].

## Netbeans :

NetBeans se place à peu près au même niveau qu'Eclipse pour moi et je trouve l'interface très vieille. Je le rajoute pour citer les quelques apports offerts pour Node.JS :

- [un premier plugin][plugin1]
- [un autre qui a l'air plus intéressant][plugin2]

## Webstorm :

Le concurrent le plus en vogue d'Eclipse est [IntelliJ][2] qui possède une version spécialement conçue pour faire du Node.JS, [Webstorm][3].

[Webstorm][3] permet de créer des squelettes de projets dont un plutôt intéressant car il permet de bien débuter avec Node.JS

> NodeJS (Node express app)

- Choix d'un template pour les pages :

    ```
    Template Engine : Jade, ejs, jshtml, hogan.js
    ```

- Choix du moteur pour le css :

    ```
    Stylesheet Engine : CSS, LESS, Stylus
    ```

## Sublime Text :

Site officiel [ici][4].

## Adobe Brackets (♥ Karlito) :

[Adobe Brackets][5] est un éditeur fait pour le design et le développement et comme la plupart des derniers éditeurs, il supporte directement [Node.JS][plugin3] et le [développement en **live**][plugin4].
