## Eclipse:

To work with Node.JS more easily, you can install the "NodeClipse" plugin available [here][1].

## Netbeans:

To me, NetBeans is roughly on the same level as Eclipse, and I find its interface very dated. I am adding it to mention the few things it offers for Node.JS:

- [a first plugin][plugin1]
- [another one that looks more interesting][plugin2]

## Webstorm:

Eclipse's trendiest competitor is [IntelliJ][2], which has a version specially designed for Node.JS: [Webstorm][3].

[Webstorm][3] can create project skeletons, including a rather interesting one because it gives you a good start with Node.JS

> NodeJS (Node express app)

- Choice of a template for the pages:

    ```
    Template Engine : Jade, ejs, jshtml, hogan.js
    ```

- Choice of the CSS engine:

    ```
    Stylesheet Engine : CSS, LESS, Stylus
    ```

## Sublime Text:

Official website [here][4].

## Adobe Brackets (♥ Karlito):

[Adobe Brackets][5] is an editor made for design and development and, like most recent editors, it directly supports [Node.JS][plugin3] and [**live** development][plugin4].

## Online editors:

- [Heroku][6]
- [Nodejitsu][7]
- [Plunker][8]
- [Cloud9 IDE][9] (from my friend [Karlito][post1])
