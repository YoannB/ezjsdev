## Eclipse:

Um einfacher mit Node.JS zu arbeiten, kann man das Plugin „NodeClipse“ installieren, das [hier][1] erhältlich ist.

## Netbeans:

Für mich liegt NetBeans ungefähr auf dem gleichen Niveau wie Eclipse, und die Oberfläche finde ich sehr altmodisch. Ich führe es auf, um die wenigen Beiträge für Node.JS zu nennen:

- [ein erstes Plugin][plugin1]
- [ein weiteres, das interessanter aussieht][plugin2]

## Webstorm:

Der angesagteste Konkurrent von Eclipse ist [IntelliJ][2], das eine speziell für Node.JS entwickelte Version hat: [Webstorm][3].

Mit [Webstorm][3] lassen sich Projektgerüste erstellen, darunter ein recht interessantes, weil es einen guten Einstieg in Node.JS ermöglicht

> NodeJS (Node express app)

- Auswahl eines Templates für die Seiten:

    ```
    Template Engine : Jade, ejs, jshtml, hogan.js
    ```

- Auswahl der CSS-Engine:

    ```
    Stylesheet Engine : CSS, LESS, Stylus
    ```

## Adobe Brackets (♥ Karlito):

[Adobe Brackets][5] ist ein Editor für Design und Entwicklung und unterstützt, wie die meisten neueren Editoren, direkt [Node.JS][plugin3] und die [**Live**-Entwicklung][plugin4].
