## Eclipse:

Per lavorare con Node.JS più facilmente, si può installare il plugin "NodeClipse" disponibile [qui][1].

## Netbeans:

Per me NetBeans è più o meno allo stesso livello di Eclipse e trovo la sua interfaccia molto datata. Lo aggiungo per citare i pochi contributi offerti per Node.JS:

- [un primo plugin][plugin1]
- [un altro che sembra più interessante][plugin2]

## Webstorm:

Il concorrente più in voga di Eclipse è [IntelliJ][2], che ha una versione pensata appositamente per Node.JS: [Webstorm][3].

[Webstorm][3] permette di creare scheletri di progetto, tra cui uno piuttosto interessante perché permette di iniziare bene con Node.JS

> NodeJS (Node express app)

- Scelta di un template per le pagine:

    ```
    Template Engine : Jade, ejs, jshtml, hogan.js
    ```

- Scelta del motore per il CSS:

    ```
    Stylesheet Engine : CSS, LESS, Stylus
    ```

## Sublime Text:

Sito ufficiale [qui][4].

## Adobe Brackets (♥ Karlito):

[Adobe Brackets][5] è un editor pensato per il design e lo sviluppo e, come la maggior parte degli editor recenti, supporta direttamente [Node.JS][plugin3] e lo [sviluppo **live**][plugin4].

- [Nodejitsu][7]
- [Plunker][8]
