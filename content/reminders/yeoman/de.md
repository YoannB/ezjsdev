Eine Sammlung von 3 Werkzeugen zum Aufsetzen moderner Webanwendungen, [offizielle Website][0].

## [Yo][1]

![Yo](/reminders/yeoman/yo.gif) yo scaffolds out a new application, writing your Grunt configuration and pulling in relevant Grunt tasks and Bower dependencies that you might need for your build.

```bash
sudo npm install -g yo
```

## [Grunt][2]

![Grunt](/reminders/yeoman/grunt.gif) Grunt is used to build, preview and test your project, thanks to help from tasks curated by the Yeoman team and grunt-contrib.

```bash
sudo npm install -g grunt-cli
```

## [Bower][3]

![Bower](/reminders/yeoman/bower.gif) Bower is used for dependency management, so that you no longer have to manually download and manage your scripts.

```bash
sudo npm install -g bower
```
