Écrire du code ES6 ou ES2015 avec Babel en un instant :).

Pour commencer, il faut ajouter les deux scripts à la fin du body :

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/babel-core/5.8.29/browser.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/babel-core/5.8.29/browser-polyfill.js"></script>
```

Et ensuite il faut une balise script en précisant bien le type _text/babel_ :

```html
<script type="text/babel">

  // ES6 code here

</script>
```
