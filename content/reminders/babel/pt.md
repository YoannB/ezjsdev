Escrever código ES6 ou ES2015 com Babel num instante :).

Para começar, é preciso adicionar os dois scripts no final do body:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/babel-core/5.8.29/browser.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/babel-core/5.8.29/browser-polyfill.js"></script>
```

Em seguida, é preciso uma tag script que indique bem o tipo _text/babel_:

```html
<script type="text/babel">

  // ES6 code here

</script>
```
